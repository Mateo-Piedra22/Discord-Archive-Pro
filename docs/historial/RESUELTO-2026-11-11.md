## Cambios de comportamiento a tener en cuenta

1. **El token guardado se invalida una vez**: el formato cambia a `dpapi:`/`plain:`.
   Si el token antiguo seguía siendo válido, se migra solo; si había caducado,
   la app lo limpia y pide uno nuevo (es lo que pasó en la prueba real: 401 → limpia).
2. **Los adjuntos nuevos se guardan con su nombre original** (`preserveFilenames`
   por defecto `true`). Las descargas antiguas tienen nombres `<hash>.png`; si
   reexportas el mismo post, convivirán ambos nombres.
3. **La cola se restaura en pausa** al abrir la app. Pulsa *Reanudar* para continuar.
4. **`strictChannelFiltering` conserva el valor guardado**. Si lo tenías activado,
   cámbialo en *Config → Avanzado* para ver todos los canales.
5. **No hay búsqueda full-text** (el índice estaba roto y no se usaba).
